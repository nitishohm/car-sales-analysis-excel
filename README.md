# Car Sales Analysis Dashboard (Excel)

## 📌 Objective
Analyze car sales and profit data to generate insights for dealership performance.

## 🛠 Tools Used
- Excel (Pivot Tables, Charts)
- Data Visualization

## 📊 Key Analysis Performed
- Quantity Sold by Dealer ID (Bar Chart)
- Profit Trends by Date and Model (Line Chart)
- Yearly Profit by Dealer (Column Chart)
- Model-specific Profit Analysis (Hudson Model)

## 🔍 Key Insights
- Identified top-performing dealers based on sales volume
- Observed profit trends across different car models
- Highlighted yearly performance variations
